# Ожидание обновления лимита Codex

Сохраните следующий запрос в текстовый файл, например `next-prompt.txt` в корне проекта, затем из корня проекта запустите:

```powershell
node scripts/wait-for-codex-quota.mjs next-prompt.txt
```

Нужны Node.js и авторизованный Codex CLI (`codex` в `PATH`). Держите терминал открытым. Скрипт сразу читает состояние пятичасового окна, повторяет запрос каждые 15 минут и запускает содержимое файла один раз после обновления квоты. Если на момент старта квота ещё доступна, скрипт ждёт *следующего* обновления. Остановить ожидание можно через Ctrl+C.

Запрос запускается как новая сессия `codex exec` в текущем каталоге с доступом на запись только к рабочему пространству. В автоматическом режиме запросы на дополнительное разрешение не показываются; операции, которым его не хватает, могут завершиться ошибкой. Скрипт выводит ход проверки и результат Codex в терминал.

Состояние читается через `account/rateLimits/read` локального Codex app-server. Для запуска требуется подтверждение сервера `ordinaryUsageAllowed`; при отсутствии такого подтверждения скрипт продолжит проверять, но не отправит промпт. Он также не запускает промпт при одном лишь достижении времени сброса.
