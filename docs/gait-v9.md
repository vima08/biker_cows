# Walk v9

Built-in `image_gen` edits, based on the original `*-brawler-walk-v2.png` strips, with each hero's combat sheet as the identity/proportions reference. CLI/API fallback was not used.

Final atlases:

- `public/assets/brawler/cassia-brawler-walk-v9.png`
- `public/assets/brawler/bruna-brawler-walk-v9.png`
- `public/assets/brawler/nova-brawler-walk-v9.png`

Each atlas is 1024×384: four 256×192 cells facing right, followed by their exact per-cell horizontal reflections facing left. Cells 1, 2 and 4 in the top row retain v2's pixels. Only cell 3 uses the generated correction. The correction is cropped by alpha and uniformly scaled to the first v2 contact's occupied height and feet baseline with nearest-neighbor sampling. The original v2, v5 and v8 files remain available.

Assembly: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-gait-v9.ps1`. Its input images are saved in `.gauntlet/gait-v9/raw/`. Visual comparison: `public/workbench/gait-v9.html`, served under `/biker_cows/workbench/gait-v9.html`.

The new third contacts reverse the near/far thigh occlusion. This is visually distinct from the unsuccessful lighting-only v5 approach. Image generation still redraws the replacement cel; its individual pixels are not identical to the combat sheet. Only the retained three cels and mirrored row have exact pixel-preservation guarantees. Judge the new contact in motion against the supplied v2/combat comparison.
