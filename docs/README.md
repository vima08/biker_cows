# Документация проекта

Этот каталог — точка входа для разработки игры.

- [Мир и предыстория](narrative.md) — сеттинг Венеры, стороны конфликта, история мира и границы сюжетного канона.
- [Героини](heroines.md) — профили Cassia, Bruna и Nova: биографии, характеры, мотивации, отношения и личные арки.
- [Враги и боссы](enemies-and-bosses.md) — рядовые противники, четыре босса, их место в истории и поведение в бою.
- [История и сюжет кампании](story.md) — пролог, три акта, переходы между игровыми режимами и эпилог.
- [Архитектура](architecture.md) — слои, зависимости и жизненный цикл приложения.
- [Модули](modules.md) — ответственность каталогов и основных классов.
- [Добавление уровня](adding-levels.md) — контракт уровня, ассеты и порядок подключения.

Команды запуска и управление остаются в корневом [README](../README.md).
