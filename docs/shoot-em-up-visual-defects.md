## Правило глубины

Сравнивается опора объекта на дороге, а не верх спрайта или нижний край прозрачной ячейки. Контакт колёс героини находится примерно на 63–69 px ниже `player.y`. У PNG ограждения есть значительное прозрачное поле снизу: его нарисованная опора находится около `y=296`, хотя якорь ячейки равен `328`.

Поэтому в обычной доступной полосе героиня закономерно может закрывать дальний знак или ограждение. Это корректное перекрытие. Проверка обратной стороны знака/ограждения использует искусственно заданную дальнюю позицию; границы движения игрока не расширялись. Нельзя просто перенести весь забор поверх всех героев: это заставило бы его пересекать торс байкера, колёса которого уже впереди забора.

- `npm run build` — проходит.
- `BCFV_URL=http://127.0.0.1:4174/biker_cows node scripts/gauntlet-rider-depth.mjs` — 31 проверка, включая 12 проверок воздушного слоя. Нужен Vite dev server, поскольку сценарий создаёт управляемую копию игры через импорт исходного модуля.
- Кадры всех трёх героинь на трёх полосах, мин на разных глубинах и процедурного режима: `.gauntlet/rider-depth/`. Машинный отчёт: `.gauntlet/rider-depth/report.json`.
- Проверка производительности мини-босса и босса: `scripts/gauntlet-boss-performance.mjs` — проходит при отдельном запуске, 59.79 / 59.88 FPS, ошибок браузера нет. Результаты в `.gauntlet/boss-performance/report.json`.
- `scripts/gauntlet-three-act-campaign.mjs` — проходит на готовой сборке (`http://127.0.0.1:4184/biker_cows`): переходы кампании, кооператив, continue, перенос вооружения и отдельные debug-маршруты. Road Rash пройден обычными управляющими командами; остальные границы актов проверены через `completeAct`, это не полный боевой проход всех уровней. Отчёт: `.gauntlet/iteration-28/campaign-contract/report.json`. Предыдущие запуски на dev-сервере прерывались уничтожением контекста страницы; финальный запуск на production preview завершился успешно.

Старые общие сценарии также запускались, но содержат несовместимые с текущей игрой ожидания: `gauntlet.mjs` ждёт готовности игровых атласов ещё в меню, где теперь действует отложенная загрузка; `gauntlet-iteration18.mjs` ждёт старой нижней границы `454` вместо текущей `404`. Оба останавливаются по тайм-ауту. Эти проверки не считаются пройденными; изменения границ движения и загрузки ресурсов не входят в визуальные исправления этого аудита.
