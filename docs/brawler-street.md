# Лента Furnace District

Порядок, ширина, тип и вывеска семи участков задаются в `FURNACE_DISTRICT.street` в `src/levels/campaign.ts`. Их суммарная ширина равна длине уровня (6700). Новая лента заменяет повторяющийся `furnace-floor.png` для этого уровня; другие определения без `street` используют прежний renderer.

`src/brawler/StreetRibbon.ts` один раз запекает каждый участок в bitmap с разрешением вдвое меньше игрового canvas. В кадре рисуются только видимые участки, без сглаживания. Фасады и машины находятся за игровой полосой; декорации не меняют коллизии. Асфальт, разметка и фасады двигаются на `worldX - cameraX`, как персонажи. Дальняя панорама использует ту же камеру с коэффициентом 0,18, без отдельного таймера и зацикливания. При смене направления и остановке камеры оба слоя остаются связаны.

Проверка: запустить Vite на порту 4173 и `npm run test:brawler-street`. Сценарий проверяет покрытие шести стыков, движение пола относительно камеры, возврат к прежним координатам, скорость и покрытие панорамы. Семь кадров настоящего renderer и отчёт сохраняются в `.gauntlet/brawler-street/`.

Разметка, пересекающая границу участков, продолжается на следующем bitmap; проверка отдельно контролирует такие стыки.

Скрипты `npm run dev`, `npm run build` и `npm run preview` используют `--configLoader runner`, чтобы Vite не требовал доступа esbuild к родительским каталогам. В PowerShell с запрещёнными `.ps1` использовать `npm.cmd`: например, `npm.cmd run dev -- --host 127.0.0.1 --port 4173` и `npm.cmd run build`.
