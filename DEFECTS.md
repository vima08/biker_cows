# Таблица дефектов

Эту таблицу заполняют пользователь и независимый critic-сабагент по итогам проверки реальной запущенной игры. В колонке `Fixed` незакрытый чекбокс означает, что дефект подтверждён и ещё не исправлен; после исправления его следует заменить на `[x]` только вместе с проверкой указанного критерия приёмки.

## Актуальная проверка — 8 сентября 2026, iteration 28

Road Rash возвращён в основную кампанию с разрешения пользователя: rider Act 1 / Magma Mauler → Sulfur Run / Road King → Furnace District / Forge Overseer → rider Act 3 / Sulfur Dreadnought → финал. Прямые Road Rash debug URL сохраняют самостоятельную победу. Continue/restart сохраняют маршрут кампании, выбранных героинь и накопленный до секции счёт; P2 возвращается в brawler после управляемой P1 дорожной секции.

Новый независимый critic оценил реальные экраны и минимум три последовательных кадра каждой основной секции, сравнил их с Road Rash Genesis, Contra Hard Corps, Gunstar Heroes, Thunder Force IV и Batman MD. Его заключение: **публичное настольное демо — 7/10; полноценный релиз — 5/10; уровень ведущих 16-битных игр — пока не достигнут**. Это экспертные оценки качества, не проценты выполненной работы. Полный независимый отзыв: `.gauntlet/iteration-28/critic/CRITIQUE.md`.

**Готовность:** игру можно показывать как desktop-демо с явно указанным ограничением co-op в Road Rash. До законченного релиза приоритетны движение полотна, читаемость контакта/врагов и единая внешность героинь. Подтверждённых crash-блокеров в выполненных проверках нет; честное непрерывное прохождение обоих shooter-актов этим аудитом не доказано.

### Подтверждённые проверки и их пределы

- `campaign-contract/report.json`: PASS. Проверены все переходы, score/history/loadout, Road pause/restart/continue, возвращение P2 и самостоятельная победа debug-сцены. Полный Road пройден обычными контролами за 43 с, итог 72 HP, King 8→7→6→5→4→3→2→1→0. Другие границы актов ускорены через debug completeAct — это проверка маршрута, не доказательство полного боевого прохождения shooter.
- `brawler/report.json`: PASS. Полный обычный brawler autoplay: 141.61 с симуляции, 22 побеждённых врага, Forge побеждён, Bruna 144/170 HP; co-op ввод и отсутствие friendly fire проверены. Boss-only debug-сцена имеет уменьшенное HP босса и отдельно не заменяет полный маршрут.
- `readiness/report.json`: смена героини, движение/стрельба, пауза, continue, работа предварительно загруженной Road-сцены при отключённой сети; runtime errors и external requests пусты. Web Audio разблокирован, события звука идут; субъективное качество звука не прослушано.
- Чистая установка: отдельная папка `clean-install`, `npm ci --offline --no-audit --no-fund` и production build — PASS, исходные node_modules не использовались.
- Performance: первый 6-секундный замер финального босса дал 55.79 FPS / p95 33.3 ms и не прошёл gate. Повторный 12-секундный замер без изменения кода прошёл: минибосс 59.91 FPS / p95 16.7 ms / simulation 1.001×; финальный 59.89 FPS / p95 16.8 ms / simulation 0.995×. Оба отчёта сохранены в `boss-performance` и `boss-performance-recheck`; устойчивую регрессию не объявляем, но перед релизом нужен повтор на целевых устройствах.
- Проверена Windows/Edge desktop-среда. Firefox/Safari, физические геймпады, touch-управление и длительное непрерывное прохождение новым игроком не проверены.

Все короткие пути к доказательствам ниже относительны к `.gauntlet/iteration-28/`. Основной capture `readiness/07-miniboss-*` ошибочно показывает меню и не используется: действительные кадры минибосса — `readiness-miniboss/07-miniboss-*`. Кадры сняты 7 сентября; заключение и сводка обновлены 8 сентября 2026.
